# MonnLang 1.5.0 — زبان فارسی‌پذیر، موتور بازی و Monn Studio

Monn یک زبان برنامه‌نویسی ساده و قابل گسترش است؛ برای کسانی که می‌خواهند بدون درگیرشدن با جزئیات Python، HTML و JavaScript رابط کاربری، ابزار، نمونهٔ اولیهٔ بازی و روایت تعاملی بسازند. فایل‌های پروژه پسوند `.monn` دارند. دستورهای قدیمی نقطه‌ای همچنان پشتیبانی می‌شوند و در کنار آن‌ها می‌توان از واژه‌های فارسی استفاده کرد.

> هدف Monn این است که «نوشتن برنامه» به چند دستور خوانا تبدیل شود؛ نه اینکه کاربر مجبور باشد از روز اول چند زبان مختلف را یاد بگیرد.

## موتور بازی داستانی Monn 1.2

Monn حالا یک موتور مستقل برای بازی‌های روایی و انتخاب‌محور دارد. هسته از رابط کاربری جداست و امکانات زیر را ارائه می‌کند:

- صحنه‌ها و انتخاب‌های شاخه‌ای
- شرط‌های قابل بررسی برای ویژگی‌ها، جان، پرچم، آیتم و مأموریت
- جان، منابع، ویژگی‌ها و کوله‌پشتی
- مأموریت‌های فعال، تکمیل‌شده و شکست‌خورده
- دفترچه وقایع و ثبت مسیر صحنه‌ها
- ذخیره و بارگذاری JSON با بررسی سازگاری پروژه
- خروجی HTML5 واکنش‌گرا با ذخیره محلی مرورگر

**راهنمای اختصاصی موتور بازی:** [docs/GAME_ENGINE_FA.md](docs/GAME_ENGINE_FA.md)

### اجرای نمونه بازی در ترمینال

```powershell
monn examples/story_adventure.mongame.json --game
```

### ساخت بازی مرورگری

```powershell
monn examples/story_adventure.mongame.json --game --web
```

خروجی پیش‌فرض کنار فایل بازی ساخته می‌شود. برای تعیین مسیر:

```powershell
monn examples/story_adventure.mongame.json --game --web --output dist/index.html
```

### ذخیره و ادامه بازی در ترمینال

```powershell
monn examples/story_adventure.mongame.json --game --save saves/slot1.json
monn examples/story_adventure.mongame.json --game --load saves/slot1.json
```

پروژه‌های بازی از فرمت JSON با پسوند `.mongame.json` استفاده می‌کنند. نمونه کامل انگلیسی: [story_adventure.mongame.json](examples/story_adventure.mongame.json)؛ نمونه با کلیدها و API فارسی: [story_persian.mongame.json](examples/story_persian.mongame.json).

### API پایتون

```python
from monn import GameEngine, load_project, compile_game_to_html

project = load_project("examples/story_adventure.mongame.json")
game = GameEngine(project)
print(game.scene)
print(game.available_choices())
game.choose("take_card")
game.save("save.json")

html = compile_game_to_html(project)
```

هستهٔ روایی و ابزارهای دوبعدی Monn قابل استفاده‌اند. یک runtime آزمایشی اکشن سه‌بعدی با Panda3D نیز وجود دارد؛ این به معنی پشتیبانی کامل از همهٔ سبک‌های اکشن یا موتور سه‌بعدی بالغ نیست. فیزیک پیشرفته، انیمیشن اسکلت‌بندی، ویرایشگر سه‌بعدی زنده و چندنفره آنلاین هنوز در حال توسعه‌اند.

## Monn Studio 1.5.0 — محیط یکپارچه بازی‌سازی

Monn Studio یک محیط گرافیکی فارسی برای ساخت بازی‌های داستانی و دوبعدی است. طراحی پروژه، شخصیت، منطق، رابط، رسانه و خروجی وب در یک گردش کار انجام می‌شود.

### امکانات اصلی
- **پیش‌نمایش زنده:** اجرای نسخهٔ فعلی بازی داخل پنجرهٔ Studio، بدون دانلود خروجی.
- **نقشهٔ داستان:** کارت‌های صحنه را جابه‌جا و مسیر انتخاب‌ها را به‌صورت بصری وصل کن.
- **منطق بصری:** چند شرط و رویداد را از فهرست انتخاب کن؛ دیگر نیازی به پنجره‌های prompt نیست.
- **شخصیت‌های چندرسانه‌ای:** تصویر، ویدیوی MP4/WebM، کلیپ‌های کوتاه یا بلند، صدا، حالت‌های چهره و مدل سه‌بعدی.
- **شخصیت هوشمند:** دستور رفتاری، قواعد پرسش/پاسخ ثابت و اتصال اختیاری به API سازگار با OpenAI.
- **جهان دوبعدی:** نقشه، اشیا، موقعیت، اندازه، Sprite Sheet، فریم و FPS، حرکت با WASD/کلیدهای جهت و برخورد مستطیلی.
- **ویرایشگر سه‌بعدی و اجرای اکشن آزمایشی:** نمای دیداری ایزومتریک برای انتخاب و جابه‌جایی اشیا، چرخش زاویه دید و بزرگ‌نمایی؛ تنظیم دوربین اول‌شخص/سوم‌شخص، گرانش، سلاح و رفتار دشمن. runtime مبتنی بر Panda3D دوربین سوم‌شخص، حرکت، شلیک با نرخ/آسیب/برد قابل تنظیم و دشمن تعقیب‌کننده دارد؛ با فرمان `monn-3d` اجرا می‌شود. این هنوز موتور سه‌بعدی کامل با فیزیک rigid-body و انیمیشن اسکلت‌بندی نیست.
- **طراح رابط کشیدنی:** افزودن متن، دکمه، تصویر، پنل، کادر ورود نام و مکان؛ جابه‌جایی و تغییر اندازه روی بوم و تنظیم رنگ، اندازه و مقصد.
- **تایم‌لاین صحنه:** لایه‌های جداگانهٔ ویدیو، صدا و انیمیشن؛ جابه‌جایی کلیپ‌ها، تعیین زمان شروع/مدت و نقاط ورود و خروج فایل؛ انیمیشن موقعیت، شفافیت و مقیاس عناصر رابط.
- **صدا:** موسیقی صحنه و منو، صدای انتخاب‌ها و صدای دیالوگ.
- **کتابخانهٔ دارایی:** ثبت پدیدآورنده، منبع و مجوز هر فایل؛ اطلاعات اعتباردهی در بازی خروجی نمایش داده می‌شود.
- **نیترو (Nitro):** دستیار هوشمند محلی متصل به Ollama؛ واژه‌نامهٔ تخصصی فارسی برای طراحی بازی دارد و می‌تواند صحنه، متن، انتخاب، شخصیت، مأموریت، گفت‌وگو، رابط، اشیای دوبعدی و سه‌بعدی، دشمن/هدف با جان و سرعت و آسیب، موقعیت بازیکن، حالت دوربین اول‌شخص/سوم‌شخص، فاصله دوربین، گرانش و تنظیمات سلاح را پیشنهاد و ویرایش کند. تغییرها ابتدا اعتبارسنجی و به‌صورت پیشنهاد نمایش داده می‌شوند؛ فقط پس از تأیید صریح کاربر اعمال می‌شوند. نیترو کد دلخواه یا فرمان سیستم‌عامل اجرا نمی‌کند.
- **حساب محلی:** ساخت پروفایل روی رایانه با گذرواژهٔ هش‌شده؛ این نسخه همگام‌سازی ابری ندارد.
- **نسخهٔ دسکتاپ ویندوز:** اجرای Studio در پنجرهٔ مستقل با آیکون Monn و ساخت میانبر دسکتاپ از بستهٔ ویندوز.
- **سامانهٔ افزونه‌ها:** کشف افزونه‌های پایتون و بارگذاری فقط پس از تأیید کاربر؛ راهنما: [docs/PLUGIN_SDK_FA.md](docs/PLUGIN_SDK_FA.md).
- **ذخیرهٔ خودکار در IndexedDB** و فایل منبع بومی .monn.

### راه‌اندازی نیترو محلی

1. Ollama را برای ویندوز نصب و اجرا کن.
2. در PowerShell مدل پیشنهادی را دریافت کن: `ollama pull qwen2.5:7b`.
3. Monn Studio را اجرا کن و از «حساب کاربری» یک پروفایل محلی بساز.
4. «نیترو AI» را باز کن، درخواستت را بنویس و پیشنهاد را بررسی کن.
5. فقط در صورت رضایت، «تأیید و اعمال تغییرها» را انتخاب کن.

مدل زبانی روی رایانهٔ خودت اجرا می‌شود و نیترو در این نسخه فقط به سرویس loopback محلی وصل می‌شود. خود Monn مدل زبانی را همراه برنامه نصب نمی‌کند.

### زبان مستقل MONN

فایل .monn اکنون از دستورهای خوانای خود زبان تشکیل می‌شود؛ مانند بازی، بازیکن، شخصیت، صحنه، انتخاب، شرط، اثر، جهان و رابط. نمونهٔ کوچک:

```text
# MONN Game Language · نسخه ۲
بازی "ماجراجویی من"
شناسه "my-game"
شروع "entrance"

بازیکن {
  جان = 100
  حداکثر_جان = 100
  ویژگی "سکه" = 0
  کوله_پشتی = []
}

صحنه "entrance" "ورودی" {
  روایت = "به ماجراجویی خوش آمدی."
  انتخاب "رفتن به حیاط" -> "yard" {
    شناسه = "go_yard"
    شرط "stat" "سکه" >= 0
    اثر "stat" "سکه" add 1
  }
}

صحنه "yard" "حیاط" {
  روایت = "به حیاط رسیدی."
}
```

نمونهٔ کامل‌تر در examples/studio_demo.monn قرار دارد.

```powershell
monn examples/studio_demo.monn --game
monn examples/studio_demo.monn --game --web --output dist/index.html
```

فایل‌های MONN نسخهٔ قدیمی که از بلوک JSON استفاده می‌کردند همچنان برای سازگاری قابل بارگذاری‌اند؛ ذخیرهٔ جدید Studio از دستورهای بومی نسخهٔ ۲ استفاده می‌کند.

## خروجی وب؛ بدون نصب سرور

Monn می‌تواند زیرمجموعهٔ قابل‌حمل زبان را به یک فایل HTML مستقل تبدیل کند. فایل خروجی را می‌توان با مرورگر باز کرد یا روی GitHub Pages، Netlify و هر میزبان فایل استاتیک قرار داد.

```powershell
monn hello.monn --web
# تعیین نام فایل خروجی
monn hello.monn --web --output dist/index.html
```

یا:
```bash
python -m monn_cli hello.monn --web -o site/index.html
```

این خروجی به سرور Monn نیاز ندارد. در حال حاضر خروجی وب برای رابط‌های عمومی، متغیرها، شرط‌ها، حلقه‌های شمارشی و ظاهر پایه طراحی شده است. برخی قابلیت‌های مخصوص دسکتاپ مانند پنجرهٔ Tkinter، مدل سه‌بعدی محلی و چت API در مرورگر معادل مستقیم ندارند و در خروجی وب با پیام راهنما مشخص می‌شوند؛ آن‌ها را نباید قابلیت وب کامل فرض کرد.

## راهنمای زبان

### متغیر و چاپ
```text
متغیر نام = امیر
متغیر امتیاز = 120
چاپ
```
نام متغیر را بعد از «متغیر» بنویس. برای خواندن مقدار متغیر در شرط از `$نام` استفاده کن. مقدارهای عددی به عدد تبدیل می‌شوند؛ متن را می‌توانی ساده بنویسی یا داخل کوتیشن قرار بدهی.

### شرط اگر / وگرنه
```text
متغیر امتیاز = 75
اگر $امتیاز >= 50
متن قبول شدی!
وگرنه
متن تلاش دوباره
پایان
```

عملگرها: `==` یا `=` برابر، `!=` نابرابر، `>` بزرگ‌تر، `<` کوچک‌تر، `>=` بزرگ‌تر یا مساوی، `<=` کوچک‌تر یا مساوی. همچنین می‌توانی از دستورهای قدیمی `????`، `?!?!` و `?????` استفاده کنی؛ شکل شرط‌دار جدید آن‌ها `???? 5 > 2` است.

### حلقه
```text
تکرار 5
متن این جمله پنج بار ساخته می‌شود
پایان حلقه
```
نسخهٔ نمادین: `......[5` و پایان آن `......]`. سقف ایمنی هر حلقه ۱۰٬۰۰۰ تکرار است. دستور `......[` یا «شروع حلقه» یک حلقهٔ تکرارشونده است؛ برای جلوگیری از حلقهٔ بی‌نهایت، داخل آن با شرط و «توقف حلقه» خارج شو. سقف ایمنی ۱۰٬۰۰۰ دور است. برای تعداد مشخص از «تکرار عدد» استفاده کن.

### دکمه‌های تعاملی و منطق بازی
برای اینکه دکمه واقعاً کاری انجام دهد، از پیکان و یک کنش امن استفاده کن:
```text
متغیر سکه = 0
دکمه برداشتن سکه => افزایش:سکه=1
دکمه دیدن پیام => پیام:در صندوق یک کلید پیدا کردی!
دکمه پاکت را باز کن => تنظیم:مرحله=2
```
کنش‌های فعلی: `پیام:متن`، `تنظیم:نام=مقدار`، `افزایش:نام=عدد`، `کاهش:نام=عدد` و `خروج`. این کنش‌ها در دسکتاپ و خروجی وب پشتیبانی می‌شوند؛ در وب نتیجه در بخش پیام صفحه نمایش داده می‌شود.

### رابط کاربری فارسی
| دستور فارسی | معادل قدیمی | کاربرد |
|---|---|---|
| پنجره | `...` | ساخت پنجره |
| دکمه متن | `.... 'متن'` | ساخت دکمه |
| متن پیام | `..... 'پیام'` | برچسب متنی |
| ورودی | `......` | کادر ورود |
| کادرمتن | `.......` | متن چندخطی |
| چک‌باکس | `........` | گزینهٔ روشن/خاموش |
| گزینه‌ها | `.........` | گزینه‌های رادیویی |
| نوارلغزنده | `..........` | انتخاب مقدار |
| پیشرفت | `...........` | نوار پیشرفت |
| قاب | `............` | قاب رابط |
| بوم | `.............` | سطح ترسیم |
| فهرست | `................` | فهرست |
| کشویی | `...............` | فهرست کشویی |
| زبانه‌ها | `.................` | تب‌ها |
| گفتگو | `..................` | پنجرهٔ چت هوش مصنوعی |

### چیدمان
پس از ساخت یک ابزار، دستور چیدمان را روی آخرین ابزار اعمال کن:
- `..<` یا «چیدمان چپ»
- `..>` یا «چیدمان راست»
- `..^` یا «چیدمان بالا»
- `..v` یا «چیدمان پایین»
- `..=` یا «وسط‌چین»

| `##fg:#ffffff` | رنگ متن |
| `##font:14` | اندازهٔ فونت |
| `##color` | انتخاب‌گر رنگ سیستم |
| `##padding:8` | فاصلهٔ ابزارها |
| `##relief:groove` | نوع قاب |
| `##cursor:hand2` | شکل نشانگر |
| `##alpha:0.95` | شفافیت پنجره |
| `##resizable:1` | تغییر اندازه |
| `تم تاریک` / `تم روشن` | پوستهٔ تیره یا روشن |

## ساخت بازی داستانی و تعاملی

Monn برای نمونه‌سازی داستان، منوها، صحنه‌ها، امتیاز و انتخاب مسیر مناسب است. نمونهٔ زیر یک اسکلت سادهٔ داستانی است؛ برای بازی کامل با ذخیره‌سازی، صدا، گرافیک و چندنفره باید ماژول‌های بازی و وب آن توسعه پیدا کنند.

```text
پنجره
##title:راز ایستگاه
##size:760x520
تم تاریک
متغیر نام = مسافر
متغیر انرژی = 3
متن به ایستگاه متروکه خوش آمدی.
متن صدایی از راهروی تاریک می‌آید.
دکمه ورود به راهرو
اگر $انرژی > 0
متن چراغ‌قوه هنوز روشن است.
وگرنه
متن همه‌جا تاریک شده است.
پایان
```

- دستورهای فارسی و نمادین هم‌زمان

- ساخت مدل‌های سادهٔ OBJ

## اتصال هوش مصنوعی

کلید API را داخل کد یا مخزن Git قرار نده. در PowerShell:
```powershell
$env:MONN_API_KEY="YOUR_SECRET_KEY"
$env:MONN_API_BASE="https://openrouter.ai/api/v1"
$env:MONN_MODEL="openrouter/free"
monn examples/ai_chat.monn
```

برای سرویس‌های دیگر، آدرس پایه و نام مدل خودشان را تنظیم کن. چت به endpoint سازگار `/chat/completions` نیاز دارد. تولید تصویر نیازمند endpoint سازگار `/images/generations` است و ممکن است توسط مدل‌های رایگان ارائه نشود.

## امنیت و محدودهٔ نسخه
- کلیدهای API را در متغیر محیطی نگه دار.
- فایل ناشناس `.monn` را پیش از اجرا بررسی کن.
- حلقهٔ شمارشی حداکثر ۱۰٬۰۰۰ بار اجرا می‌شود.
- خروجی وب یک کامپایلر سمت‌کاربر برای زیرمجموعهٔ زبان است؛ هنوز جایگزین کامل موتور دسکتاپ نیست.
- قابلیت‌هایی مثل پایگاه‌داده، حساب کاربری، بازی چندنفرهٔ هم‌زمان، شبکهٔ امن، موتور فیزیک و تولید عمومی مدل سه‌بعدی هنوز ماژول‌های مستقل آینده هستند و نباید به‌عنوان آماده و پیاده‌سازی‌شده معرفی شوند.
