# MonnLang 1.1 — زبان فارسی‌پذیر برای ساخت برنامه و وب

Monn یک زبان برنامه‌نویسی ساده و قابل گسترش است؛ برای کسانی که می‌خواهند بدون درگیرشدن با جزئیات Python، HTML و JavaScript رابط کاربری، ابزار، نمونهٔ اولیهٔ بازی و روایت تعاملی بسازند. فایل‌های پروژه پسوند `.monn` دارند. دستورهای قدیمی نقطه‌ای همچنان پشتیبانی می‌شوند و در کنار آن‌ها می‌توان از واژه‌های فارسی استفاده کرد.

> هدف Monn این است که «نوشتن برنامه» به چند دستور خوانا تبدیل شود؛ نه اینکه کاربر مجبور باشد از روز اول چند زبان مختلف را یاد بگیرد.

## راهنمای کامل
راهنمای مرجع فارسی، شامل نصب، دستورها، شرط‌ها، حلقه‌ها، رابط کاربری، کنش دکمه‌ها و خروجی وب: [docs/REFERENCE_FA.md](docs/REFERENCE_FA.md)

## شروع سریع

### نصب در ویندوز
1. Python نسخهٔ 3.8 یا جدیدتر را از python.org نصب کن و گزینهٔ Add Python to PATH را فعال کن.
2. ترمینال PowerShell را باز کن.
3. مخزن را دریافت و نصب کن:

```powershell
git clone https://github.com/AmirHosseinNzafat/monn.git
cd monn
py -m pip install -e ".[all]"
```

برای نصب پایه بدون ابزار تصویر و سه‌بعدی:
```powershell
py -m pip install -e .
```

### نصب در Linux و macOS
```bash
git clone https://github.com/AmirHosseinNzafat/monn.git
cd monn
python3 -m pip install -e ".[all]"
```

## اولین برنامهٔ فارسی

فایل `hello.monn` بساز و این را در آن قرار بده:

```text
پنجره
##title:اولین برنامه من
##size:640x420
تم تاریک
متن سلام! به دنیای Monn خوش آمدی.
دکمه شروع
ورودی
```

اجرا:
```powershell
monn hello.monn
# یا
py -m monn_cli hello.monn
```

## خروجی وب؛ بدون نصب سرور

Monn می‌تواند زیرمجموعهٔ قابل‌حمل زبان را به یک فایل HTML مستقل تبدیل کند. فایل خروجی را می‌توان با مرورگر باز کرد یا روی GitHub Pages، Netlify و هر میزبان فایل استاتیک قرار داد.

```powershell
monn hello.monn --web
# تعیین نام فایل خروجی
monn hello.monn --web --output dist/index.html
```

یا:
```bash
python -m monn_cli hello.monn --web -o site/index.html
```

این خروجی به سرور Monn نیاز ندارد. در حال حاضر خروجی وب برای رابط‌های عمومی، متغیرها، شرط‌ها، حلقه‌های شمارشی و ظاهر پایه طراحی شده است. برخی قابلیت‌های مخصوص دسکتاپ مانند پنجرهٔ Tkinter، مدل سه‌بعدی محلی و چت API در مرورگر معادل مستقیم ندارند و در خروجی وب با پیام راهنما مشخص می‌شوند؛ آن‌ها را نباید قابلیت وب کامل فرض کرد.

## راهنمای زبان

### متغیر و چاپ
```text
متغیر نام = امیر
متغیر امتیاز = 120
چاپ
```
نام متغیر را بعد از «متغیر» بنویس. برای خواندن مقدار متغیر در شرط از `$نام` استفاده کن. مقدارهای عددی به عدد تبدیل می‌شوند؛ متن را می‌توانی ساده بنویسی یا داخل کوتیشن قرار بدهی.

### شرط اگر / وگرنه
```text
متغیر امتیاز = 75
اگر $امتیاز >= 50
متن قبول شدی!
وگرنه
متن تلاش دوباره
پایان
```

عملگرها: `==` یا `=` برابر، `!=` نابرابر، `>` بزرگ‌تر، `<` کوچک‌تر، `>=` بزرگ‌تر یا مساوی، `<=` کوچک‌تر یا مساوی. همچنین می‌توانی از دستورهای قدیمی `????`، `?!?!` و `?????` استفاده کنی؛ شکل شرط‌دار جدید آن‌ها `???? 5 > 2` است.

### حلقه
```text
تکرار 5
متن این جمله پنج بار ساخته می‌شود
پایان حلقه
```
نسخهٔ نمادین: `......[5` و پایان آن `......]`. سقف ایمنی هر حلقه ۱۰٬۰۰۰ تکرار است. دستور `......[` یا «شروع حلقه» یک حلقهٔ تکرارشونده است؛ برای جلوگیری از حلقهٔ بی‌نهایت، داخل آن با شرط و «توقف حلقه» خارج شو. سقف ایمنی ۱۰٬۰۰۰ دور است. برای تعداد مشخص از «تکرار عدد» استفاده کن.

### دکمه‌های تعاملی و منطق بازی
برای اینکه دکمه واقعاً کاری انجام دهد، از پیکان و یک کنش امن استفاده کن:
```text
متغیر سکه = 0
دکمه برداشتن سکه => افزایش:سکه=1
دکمه دیدن پیام => پیام:در صندوق یک کلید پیدا کردی!
دکمه پاکت را باز کن => تنظیم:مرحله=2
```
کنش‌های فعلی: `پیام:متن`، `تنظیم:نام=مقدار`، `افزایش:نام=عدد`، `کاهش:نام=عدد` و `خروج`. این کنش‌ها در دسکتاپ و خروجی وب پشتیبانی می‌شوند؛ در وب نتیجه در بخش پیام صفحه نمایش داده می‌شود.

### رابط کاربری فارسی
| دستور فارسی | معادل قدیمی | کاربرد |
|---|---|---|
| پنجره | `...` | ساخت پنجره |
| دکمه متن | `.... 'متن'` | ساخت دکمه |
| متن پیام | `..... 'پیام'` | برچسب متنی |
| ورودی | `......` | کادر ورود |
| کادرمتن | `.......` | متن چندخطی |
| چک‌باکس | `........` | گزینهٔ روشن/خاموش |
| گزینه‌ها | `.........` | گزینه‌های رادیویی |
| نوارلغزنده | `..........` | انتخاب مقدار |
| پیشرفت | `...........` | نوار پیشرفت |
| قاب | `............` | قاب رابط |
| بوم | `.............` | سطح ترسیم |
| فهرست | `................` | فهرست |
| کشویی | `...............` | فهرست کشویی |
| زبانه‌ها | `.................` | تب‌ها |
| گفتگو | `..................` | پنجرهٔ چت هوش مصنوعی |

### چیدمان
پس از ساخت یک ابزار، دستور چیدمان را روی آخرین ابزار اعمال کن:
- `..<` یا «چیدمان چپ»
- `..>` یا «چیدمان راست»
- `..^` یا «چیدمان بالا»
- `..v` یا «چیدمان پایین»
- `..=` یا «وسط‌چین»

### رنگ و ظاهر
| دستور | عملکرد |
|---|---|
| `##bg:#172033` | رنگ پس‌زمینه |
| `##fg:#ffffff` | رنگ متن |
| `##font:14` | اندازهٔ فونت |
| `##color` | انتخاب‌گر رنگ سیستم |
| `##padding:8` | فاصلهٔ ابزارها |
| `##relief:groove` | نوع قاب |
| `##cursor:hand2` | شکل نشانگر |
| `##alpha:0.95` | شفافیت پنجره |
| `##resizable:1` | تغییر اندازه |
| `تم تاریک` / `تم روشن` | پوستهٔ تیره یا روشن |

## ساخت بازی داستانی و تعاملی

Monn برای نمونه‌سازی داستان، منوها، صحنه‌ها، امتیاز و انتخاب مسیر مناسب است. نمونهٔ زیر یک اسکلت سادهٔ داستانی است؛ برای بازی کامل با ذخیره‌سازی، صدا، گرافیک و چندنفره باید ماژول‌های بازی و وب آن توسعه پیدا کنند.

```text
پنجره
##title:راز ایستگاه
##size:760x520
تم تاریک
متغیر نام = مسافر
متغیر انرژی = 3
متن به ایستگاه متروکه خوش آمدی.
متن صدایی از راهروی تاریک می‌آید.
دکمه ورود به راهرو
اگر $انرژی > 0
متن چراغ‌قوه هنوز روشن است.
وگرنه
متن همه‌جا تاریک شده است.
پایان
```

## اتصال هوش مصنوعی

کلید API را داخل کد یا مخزن Git قرار نده. در PowerShell:
```powershell
$env:MONN_API_KEY="YOUR_SECRET_KEY"
$env:MONN_API_BASE="https://openrouter.ai/api/v1"
$env:MONN_MODEL="openrouter/free"
monn examples/ai_chat.monn
```

برای سرویس‌های دیگر، آدرس پایه و نام مدل خودشان را تنظیم کن. چت به endpoint سازگار `/chat/completions` نیاز دارد. تولید تصویر نیازمند endpoint سازگار `/images/generations` است و ممکن است توسط مدل‌های رایگان ارائه نشود.

## ابزارهای رسانه‌ای اختیاری
```powershell
py -m pip install Pillow

```
- `..openimage`: انتخاب و نمایش تصویر
- `..model3d`: نمایش OBJ/STL/PLY/GLB

- `..image:prompt`: درخواست تولید تصویر از سرویس سازگار

## خطایابی و اجرای تست‌ها
```powershell
py -m compileall monn monn_cli.py
py -m unittest discover -s tests -v
```
اگر دستوری شناخته نشد، متن خطا شمارهٔ خط را نشان می‌دهد. مطمئن شو بلوک شرط با «پایان» و حلقه با «پایان حلقه» بسته شده باشد.

## امنیت و محدودهٔ نسخه
- کلیدهای API را در متغیر محیطی نگه دار.
- فایل ناشناس `.monn` را پیش از اجرا بررسی کن.
- حلقهٔ شمارشی حداکثر ۱۰٬۰۰۰ بار اجرا می‌شود.
- خروجی وب یک کامپایلر سمت‌کاربر برای زیرمجموعهٔ زبان است؛ هنوز جایگزین کامل موتور دسکتاپ نیست.
- قابلیت‌هایی مثل پایگاه‌داده، حساب کاربری، بازی چندنفرهٔ هم‌زمان، شبکهٔ امن، موتور فیزیک و تولید عمومی مدل سه‌بعدی هنوز ماژول‌های مستقل آینده هستند و نباید به‌عنوان آماده و پیاده‌سازی‌شده معرفی شوند.
