# MonnLang

زبان نقطه‌ای Monn برای ساخت رابط گرافیکی دسکتاپ با Python و Tkinter.

- پسوند فایل‌ها: `.monn`
- نیازمندی: Python 3.8+
- وابستگی خارجی: ندارد (Tkinter باید همراه Python نصب باشد)

## نصب از مخزن

```bash
git clone https://github.com/AmirHosseinNzafat/monn.git
cd monn
python -m pip install .
```

## اجرا

```bash
monn examples/hello.monn
```

یا:

```bash
python -m monn_cli examples/hello.monn
```

## نمونه زبان

```text
...
##title:سلام Monn
##size:500x300
##bg:#20242b
..... 'به MonnLang خوش آمدید'
.... 'شروع'
...... 
...quit
```

## دستورهای فعلی

| دستور | عملکرد |
|---|---|
| `...` | ساخت پنجره اصلی |
| `... | /// {n} .>>...` | پنجره شناور با متن |
| `.... '{t}'` | دکمه |
| `..... '{t}'` | برچسب |
| `......` | ورودی متن |
| `.......` | کادر چندخطی |
| `........` | چک‌باکس |
| `... <<<` / `... >>>` | کوچک‌سازی / بزرگ‌سازی |
| `... xxx` | بستن پنجره |
| `... ???` / `... !!!` | مخفی / نمایش پنجره |
| `... @top` | همیشه در بالاترین لایه |
| `##title:{t}` | عنوان پنجره |
| `##size:{w}x{h}` | اندازه پنجره |
| `##bg:{c}` | رنگ پس‌زمینه |
| `..calc` | ماشین‌حساب |
| `$$ {name} = {val}` | تعریف متغیر |
| `$$print` | چاپ متغیرها |
| `...quit` | خروج |

ساختار بلوک‌ها:
- `......[{n}` و `......]`: تکرار تعداد مشخص
- `......[` و `......]`: بلوک تکرار (در نسخه فعلی یک بار اجرا می‌شود)
- `????` و `?????`: بلوک شرطی پایه؛ ارزیابی شرط هنوز کامل نشده است.

> توجه: فهرست COMMANDS شامل تعدادی شناسهٔ رزروشده/آزمایشی نیز هست. هر دستور رزروشده لزوماً در مفسر پیاده‌سازی نشده است؛ دستورات پیاده‌سازی‌نشده هشدار می‌دهند. ادعای «۱۰۰+ دستور کامل» در این نسخه وجود ندارد.

## امنیت

کد Monn مستقیماً با `eval` اجرا نمی‌شود. فایل‌های ناشناس را فقط پس از بررسی اجرا کنید؛ دستورهای رابط گرافیکی می‌توانند پنجره ایجاد یا ببندند.
