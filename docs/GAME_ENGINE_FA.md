# راهنمای موتور بازی Monn 1.2

این راهنما موتور بازی داستانی Monn را توضیح می‌دهد. موتور از رابط گرافیکی مستقل است؛ یعنی یک پروژه را می‌توان با اجرای خط فرمان یا به شکل یک بازی HTML5 در مرورگر اجرا کرد.

## قابلیت‌های نسخه ۱.۲

- صحنه‌های متعدد و اتصال آن‌ها با انتخاب بازیکن
- انتخاب‌های شرطی بر اساس ویژگی، جان، پرچم، آیتم و وضعیت مأموریت
- ویژگی‌های بازیکن مثل سکه، تجربه و امتیاز
- جان و حداکثر جان با محدودسازی خودکار
- کوله‌پشتی با افزودن، مصرف و تنظیم تعداد آیتم
- مأموریت با وضعیت فعال، تکمیل‌شده و شکست‌خورده
- دفترچه وقایع داستان
- ثبت صحنه‌های بازدیدشده و شماره نوبت
- ذخیره امن و اتمیک در فایل JSON و بررسی تعلق ذخیره به نسخه همان بازی
- خروجی HTML5 مستقل با ظاهر واکنش‌گرا
- ذخیره و بارگذاری محلی در مرورگر با localStorage

این موتور فعلاً بازی داستانی و انتخاب‌محور است؛ موتور سه‌بعدی، فیزیک، چندنفره آنلاین و ویرایشگر بصری در این نسخه پیاده‌سازی نشده‌اند.

## پشتیبانی از کلیدها و API فارسی

برای ساخت پروژه لازم نیست نام فیلدهای JSON را انگلیسی بنویسی. موتور معادل‌های فارسی را نیز می‌شناسد؛ نمونه کامل در `examples/story_persian.mongame.json` قرار دارد.

نمونه کوتاه:

```json
{
  "اطلاعات": {
    "شناسه": "بازی-من",
    "عنوان": "ماجراجویی من",
    "صحنه_شروع": "آغاز"
  },
  "بازیکن": {
    "جان": 100,
    "حداکثر_جان": 100,
    "ویژگی‌ها": {"سکه": 0},
    "کوله‌پشتی": []
  },
  "صحنه‌ها": [
    {
      "شناسه": "آغاز",
      "عنوان": "اتاق آغاز",
      "روایت": "داستان از اینجا شروع می‌شود.",
      "انتخاب‌ها": [
        {
          "متن": "رفتن به جنگل",
          "مقصد": "جنگل",
          "شرط‌ها": [],
          "اثرها": [
            {"نوع": "ویژگی", "نام": "سکه", "عملیات": "افزودن", "مقدار": 5}
          ]
        }
      ]
    }
  ]
}
```

در کلیدهای فارسی، این معادل‌ها پشتیبانی می‌شوند: «ویژگی»، «جان»، «پرچم»، «آیتم»، «مأموریت»، «دفترچه»، «افزودن»، «تنظیم»، «کاهش»، «مصرف»، «شروع»، «تکمیل» و «شکست». عملگرهای ریاضی را می‌توانی با نمادهای معمول یا واژه‌های «برابر»، «نابرابر»، «بزرگتر»، «کوچکتر»، «بزرگتر_مساوی» و «کوچکتر_مساوی» بنویسی.

API پایتون نیز نام‌های فارسی دارد:

```python
from monn import موتور_بازی, پروژه_بازی, بارگذاری_بازی, ساخت_بازی_وب

پروژه = بارگذاری_بازی("examples/story_persian.mongame.json")
بازی = موتور_بازی(پروژه)
print(بازی.صحنه)
print(بازی.انتخاب_های_در_دسترس())
بازی.انتخاب("برداشتن_نقشه")
print(بازی.وضعیت())
بازی.ذخیره("ذخیره.json")
```

\`\`\`powershell

## ۵. انتخاب‌ها و شرط‌ها

هر انتخاب دارای متن و مقصد است. مقصد را با شناسه صحنه بنویس. مقدار null به معنی پایان مسیر است.

\`\`\`json
{
  "id": "open_door",
  "text": "بازکردن در",
  "target": "secret_room",
  "conditions": [
    {"type": "item", "name": "کلید", "op": ">=", "value": 1},
    {"type": "stat", "name": "سکه", "op": ">=", "value": 5}
  ],
  "effects": []
}
\`\`\`

شرط‌ها:
- \`stat\`: مقدار ویژگی بازیکن
- \`health\`: جان فعلی
- \`flag\`: پرچم منطقی یا متنی
- \`item\`: تعداد آیتم در کوله‌پشتی
- \`quest\`: وضعیت مأموریت

عملگرها: \`==\`، \`=\`، \`!=\`، \`>\`، \`<\`، \`>=\` و \`<=\`. تمام شرط‌های یک انتخاب باید درست باشند تا آن انتخاب نمایش داده شود.

## ۶. اثرهای انتخاب

اثرها به ترتیب اجرا می‌شوند. اگر یکی از اثرها خطا بدهد، موتور وضعیت را به قبل از انتخاب برمی‌گرداند.

### ویژگی‌ها

\`\`\`json
{"type": "stat", "name": "سکه", "op": "add", "value": 5}
{"type": "stat", "name": "تجربه", "op": "set", "value": 100}
{"type": "stat", "name": "سکه", "op": "subtract", "value": 2}
\`\`\`

### جان

\`\`\`json
{"type": "health", "op": "add", "value": 10}
{"type": "health", "op": "subtract", "value": 25}
{"type": "health", "op": "set", "value": 100}
\`\`\`

جان بین صفر و حداکثر جان محدود می‌شود. رسیدن جان به صفر بازی را پایان می‌دهد.

### آیتم‌ها

\`\`\`json
{"type": "item", "name": "کلید", "action": "add", "count": 1}
{"type": "item", "name": "معجون", "action": "remove", "count": 1}
{"type": "item", "name": "سکه", "action": "set", "count": 20}
\`\`\`

اگر بازیکن آیتم لازم برای مصرف را نداشته باشد، انتخاب اجرا نمی‌شود و هیچ‌یک از اثرهای قبلی آن انتخاب باقی نمی‌مانند.

### پرچم‌ها

\`\`\`json
{"type": "flag", "name": "در_باز_شد", "value": true}
\`\`\`

### مأموریت‌ها

ابتدا مأموریت را در آرایه quests تعریف کن:

\`\`\`json
{"id": "find_key", "title": "پیدا کردن کلید"}
\`\`\`

سپس از اثر استفاده کن:

\`\`\`json
{"type": "quest", "id": "find_key", "action": "start"}
{"type": "quest", "id": "find_key", "action": "complete"}
{"type": "quest", "id": "find_key", "action": "fail"}
\`\`\`

### دفترچه وقایع

\`\`\`json
{"type": "journal", "text": "روی دیوار یک پیام رمزآلود دیدم."}
\`\`\`


## ۷. شخصیت، دیالوگ و رسانه صحنه

برای تعریف شخصیت‌های قابل استفاده در گفتگو:

```json
"characters": [
  {"id": "guard", "name": "نگهبان", "portrait": "assets/guard.webp"}
]
```

هر صحنه می‌تواند تصویر، موسیقی و چند خط دیالوگ داشته باشد:

```json
{
  "id": "gate",
  "title": "دروازه",
  "image": "assets/gate.webp",
  "music": "assets/ambient.ogg",
  "dialogue": [
    {"character": "guard", "text": "ایست! کارت شناسایی‌ات را نشان بده."}
  ],
  "text": "دروازه سنگین در برابر تو قرار دارد.",
  "choices": []
}
```

مسیرهای دارایی می‌توانند نسبی به فایل HTML یا نشانی HTTP/HTTPS باشند. طرح مرورگر تصویر صحنه، تصویر شخصیت و کنترل پخش موسیقی را نمایش می‌دهد. پخش خودکار موسیقی فعال نیست؛ بازیکن از کنترل پخش استفاده می‌کند. فایل‌های محلی باید کنار خروجی وب و در مسیر نسبی درست قرار گیرند.

## ۸. استفاده از موتور در Python

\`\`\`python
from monn import GameEngine, load_project

project = load_project("examples/story_adventure.mongame.json")
game = GameEngine(project)

print(game.scene["title"])
print(game.available_choices())

game.choose("take_card")  # شناسه انتخاب
print(game.snapshot())

game.save("save.json")
game.load("save.json")
\`\`\`

همچنین می‌توان به جای شناسه، متن دقیق انتخاب یا شماره داخلی انتخاب در همان صحنه را به \`choose\` داد.

ساخت خروجی وب از Python:

\`\`\`python
from monn import load_project, compile_game_to_html

project = load_project("examples/story_adventure.mongame.json")
html = compile_game_to_html(project)
with open("game.html", "w", encoding="utf-8") as file:
    file.write(html)
\`\`\`

## ۹. تست و عیب‌یابی

\`\`\`powershell
py -m compileall -q monn monn_cli.py
py -m unittest discover -s tests -v
\`\`\`

در صورت نصب Node.js، تست خودکار ساختار نحوی JavaScript خروجی وب نیز اجرا می‌شود.

خطاهای رایج:
- صحنه شروع پیدا نشد: مقدار meta.start_scene باید با id یک صحنه برابر باشد.
- صحنه مقصد وجود ندارد: target را با شناسه دقیق صحنه تطبیق بده.
- مأموریت تعریف نشده: پیش از اثر quest، مأموریت را در quests اضافه کن.
- انتخاب در دسترس نیست: ممکن است یکی از شرط‌های آن برقرار نباشد.
- آیتم کافی وجود ندارد: تعداد آیتم لازم برای مصرف را بررسی کن.
- ذخیره متعلق به نسخه دیگری است: ذخیره فقط برای همان محتوای پروژه معتبر است؛ تغییر پروژه fingerprint را عوض می‌کند.

## ۱۰. محدوده و نقشه راه

نسخه فعلی هسته داستان و منطق بازیکن را پوشش می‌دهد. برای نزدیک‌شدن به یک محیط کامل بازی‌سازی، گام‌های بعدی عبارت‌اند از:
1. ویرایشگر بصری صحنه‌ها و انتخاب‌ها
2. مدیریت دارایی‌ها: تصویر، صدا، موسیقی و فونت
3. سیستم شخصیت‌ها، دیالوگ شاخه‌ای و انیمیشن دوبعدی
4. نقشه و سیستم رویدادهای بازی
5. آزمون مرورگری واقعی و بسته‌بندی قابل انتشار
6. در مرحله‌ای جداگانه: حساب کاربری و بازی چندنفره با سرور امن

قابلیت‌های چندنفره، موتور فیزیک و ویرایشگر گرافیکی هنوز در این نسخه آماده نیستند.
