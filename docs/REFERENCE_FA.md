# راهنمای جامع MonnLang 1.1

این سند مرجع فرمان‌های زبان است. Monn در این نسخه دو مسیر اجرا دارد:
1. **دسکتاپ**: اجرای مستقیم با مفسر Python و رابط Tkinter
2. **وب**: تبدیل بخش قابل‌حمل برنامه به یک فایل HTML مستقل

## ۱. ساختار فایل و قواعد نوشتن
- هر دستور در یک خط جدا نوشته می‌شود.
- فایل با کدگذاری UTF-8 و پسوند `.monn` ذخیره شود.
- خط خالی مجاز است.
- خطی که با `# ` شروع شود، توضیح است.
- فاصلهٔ ابتدا و انتهای خط نادیده گرفته می‌شود.
- متن فارسی، اعداد و نشانه‌های معمول در مقدارها مجازند.
- نام متغیر بهتر است بدون فاصله باشد؛ برای نام‌های چندبخشی از زیرخط استفاده کن.

## ۲. نصب و اجرای برنامه

### ویندوز
```powershell

cd monn
py -m pip install -e ".[all]"

```

```bash
git clone https://github.com/AmirHosseinNzafat/monn.git

```

نصب پایه بدون کتابخانه‌های رسانه‌ای:


## ۵. متغیرها و مقدارها

```text
متغیر نام = امیر
متغیر امتیاز = 120
متغیر فعال = درست
چاپ
```

برای استفاده از متغیر در شرط، نام آن را با علامت دلار بنویس: `$امتیاز`.
مقدارهای عددی به عدد تبدیل می‌شوند. مقدارهای درست/نادرست با `درست` و `نادرست` نوشته می‌شوند. برای چاپ وضعیت متغیرها از `چاپ` یا `$$print` استفاده کن.

## ۶. شرط‌ها

```text
اگر $امتیاز >= 100
متن عالی بود!
وگرنه
متن هنوز جا برای پیشرفت هست.
پایان
```

عملگرها:
- `==` یا `=`: برابر
- `!=`: نابرابر
- `>`: بزرگ‌تر
- `<`: کوچک‌تر
- `>=`: بزرگ‌تر یا مساوی
- `<=`: کوچک‌تر یا مساوی

معادل نمادین:
```text
???? 10 > 5
..... 'شرط درست است'
?!?! 
..... 'شرط نادرست است'
?????
```
فرم کوتاه قدیمی `????` بدون پارامتر، برای سازگاری همیشه درست محسوب می‌شود؛ برای شرط واقعی از فرم دارای عملگر استفاده کن.

## ۷. حلقه‌ها

حلقهٔ شمارشی با «تکرار عدد» اجرا می‌شود. حلقهٔ باز با «شروع حلقه» یا `......[` شروع می‌شود و باید با شرط، «توقف حلقه» را اجرا کند:

```text
متغیر شمارنده = 0
شروع حلقه
متن دور تازه
اگر $شماره_تکرار >= 3
توقف حلقه
پایان
پایان حلقه
```

```text
تکرار 3
متن این خط سه بار اجرا می‌شود
پایان حلقه
```

فرم نمادین: `......[3`، بدنه و سپس `......]`.
درون حلقه، متغیر `$شماره_تکرار` از ۱ تا تعداد تکرار و `$loop_index` از صفر آغاز می‌شود.
برای جلوگیری از قفل‌شدن برنامه، سقف هر حلقه ۱۰٬۰۰۰ دور است. حلقهٔ باز باید با «توقف حلقه» در یک شرط متوقف شود؛ اگر به سقف برسد، خطای زمان اجرا می‌گیری.

## ۸. کنش دکمه‌ها و بازی‌های روایی

فرم کلی:
```text
دکمه عنوان دکمه => نوع‌کنش:مقدار
```

کنش‌های داخلی:
| کنش | نمونه | نتیجه |
|---|---|---|
| پیام | `پیام:کلید را پیدا کردی` | نمایش پیام |
| تنظیم | `تنظیم:مرحله=2` | تغییر مقدار متغیر |
| افزایش | `افزایش:سکه=5` | افزایش مقدار |
| کاهش | `کاهش:جان=1` | کاهش مقدار |
| خروج | `خروج` | بستن برنامه |

نمونه:
```text
پنجره
##title:ماجرای جنگل
متغیر جان = 3
متغیر سکه = 0
متن شب شده و دو مسیر پیش روی توست.
دکمه رفتن به غار => کاهش:جان=1
دکمه برداشتن سکه => افزایش:سکه=1
دکمه خواندن یادداشت => پیام:روی کاغذ نوشته شده: به صدای آب اعتماد کن.
```

این قابلیت‌ها یک هستهٔ اولیه برای بازی روایی و انتخاب‌محور فراهم می‌کنند. ذخیرهٔ دائمی بازی، سیستم صحنه‌های پیشرفته، موسیقی پویا، انیمیشن، فیزیک، حساب کاربری و چندنفره هنوز ماژول‌های تکمیلی هستند.

## ۹. چیدمان ابزارها
بعد از ساخت یک ابزار، دستور چیدمان را بنویس تا روی آخرین ابزار ساخته‌شده اعمال شود:
- `..<` یا `چیدمان چپ`
- `..>` یا `چیدمان راست`
- `..^` یا `چیدمان بالا`
- `..v` یا `چیدمان پایین`
- `..=` یا `وسط‌چین`

## ۱۰. تصویر و سه‌بعدی
نصب:
```powershell
py -m pip install Pillow trimesh matplotlib
```
فرمان‌ها:
- `تصویر توضیح تصویر` یا `..image:prompt`: درخواست تولید تصویر از API سازگار
- `بازکردن تصویر` یا `..openimage`: انتخاب تصویر محلی
- `نمایش سه‌بعدی` یا `..model3d`: انتخاب مدل سه‌بعدی
- `ساخت سه‌بعدی cube` یا `..create3d:cube`: تولید مدل OBJ پایه
- شکل‌های پایهٔ تولیدی: `cube`، `pyramid`، `diamond`

تولید تصویر به API دارای endpoint سازگار با `/images/generations` نیاز دارد. نمایش مدل‌های پیچیده به نصب وابستگی‌ها و سازگاری فایل وابسته است.

## ۱۱. اتصال چت هوش مصنوعی
PowerShell:
```powershell
$env:MONN_API_KEY="کلید خصوصی"
$env:MONN_API_BASE="https://openrouter.ai/api/v1"
$env:MONN_MODEL="openrouter/free"
monn examples/ai_chat.monn
```
متغیرهای قابل تنظیم:
- `MONN_API_KEY`: کلید خصوصی
- `MONN_API_BASE`: آدرس پایهٔ API
- `MONN_MODEL`: شناسهٔ مدل
- `MONN_IMAGE_API_BASE`: آدرس API تصویر
- `MONN_IMAGE_MODEL`: شناسهٔ مدل تصویر

کلید را داخل فایل برنامه یا مخزن عمومی قرار نده. چت و تولید تصویر دو قابلیت جدا هستند و ممکن است یک ارائه‌دهنده فقط یکی از آن‌ها را پشتیبانی کند.

## ۱۲. خروجی وب
```powershell
monn examples/story_game.monn --web
monn examples/story_game.monn --web --output site/index.html
```
فایل HTML را می‌توان مستقیم در مرورگر باز کرد. برای انتشار عمومی می‌توان از میزبانی استاتیک استفاده کرد. خروجی وب از ابزارهای رابط عمومی، شرط، حلقهٔ شمارشی، ظاهر پایه و کنش‌های ساده پشتیبانی می‌کند. برخی امکانات دسکتاپ، چت API و نمایش سه‌بعدی در این کامپایلر وب هنوز معادل کامل ندارند.

## ۱۳. خطایابی و تست
```powershell
py -m compileall monn monn_cli.py
py -m unittest discover -s tests -v
```
- خط ناشناخته: املای دستور و فاصله‌ها را بررسی کن.
- بلوک بسته‌نشده: برای هر شرط «پایان» و برای هر حلقه «پایان حلقه» قرار بده.
- API ناموفق: کلید، مدل، آدرس پایه و محدودیت‌های ارائه‌دهنده را بررسی کن.
- ابزار رسانه‌ای ناموجود: وابستگی اختیاری مربوط را نصب کن.

## ۱۴. محدودهٔ فنی نسخهٔ ۱.۱
Monn یک پروژهٔ در حال توسعه است، نه موتور کامل بازی یا جایگزین تمام زبان‌های وب. مفسر دسکتاپ بر پایهٔ Tkinter است و کامپایلر وب یک زیرمجموعهٔ مستقل از زبان را به HTML/JavaScript تبدیل می‌کند. برای موتور کامل بازی داستانی، سیستم صحنه، ذخیره‌سازی، صدا، دارایی‌ها و ابزار طراحی بصری باید در نسخه‌های بعدی به شکل ماژولار اضافه شوند.
